# Workspace instructions

1. At the beginning of every task in this workspace, read `agent.md` before planning or changing the project.
2. Treat `agent.md` as the current project source of truth for scope, confirmed decisions, architecture, risks, acceptance criteria, and next actions.
3. Whenever a conversation changes any of those items, update `agent.md` in the same turn. Rewrite affected sections so the file reflects the latest truth; do not leave contradictory or obsolete guidance in place.
4. Before updating `agent.md`, read its current contents and preserve still-valid confirmed decisions. Record material decision changes in its decision log.
5. Do not claim that an unconfirmed proposal is a confirmed decision. Clearly label assumptions, proposals, and open questions.
