PDF 转 Markdown

这是一个面向本地办公场景的 PDF 转 Markdown 工具，支持上传 PDF、自动转换为 Markdown、OCR 识别扫描页，并提供网页体验。

  • 上传 PDF 后自动生成 Markdown
  • 扫描页自动走 OCR，保留页码标记
  • 提供本地网页界面，并可在 GitHub 上托管源码与静态展示页
查看 GitHub 仓库 查看部署工作流

说明：GitHub Pages 只适合托管静态页面；当前 FastAPI 后端仍需单独部署到支持 Python 的服务上。仓库源码和这个静态预览页已经放在 GitHub。

本地运行方式：

python -m pip install -e ".[web,test]"
python -m pip install "paddlepaddle==3.3.1"
python -m pip install -e ".[ocr]"
